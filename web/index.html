开始前，
你可能想知道。

需要安装 Claude Code 吗？+

不需要。Claude 凹3 是独立的终端阅读器，借鉴编码终端的界面风格。阅读不调用模型，不需要 Claude 账号或 API Key，也不会修改你的 claude 命令。

网页里可以直接阅读吗？+

这里展示的是实际运行的终端录屏，正文使用自拟示例。安装后，可以在 Mac 应用或自己的终端中搜索和阅读；网页不连接你的本地终端。

Intel Mac 和 Linux 可以用吗？+

本轮 Mac 应用和一键安装包面向 Apple Silicon。Intel Mac 和 Linux 可从 GitHub 源码安装，需要 Python 3.11 及以上；目前没有对应的预编译下载包。

书源和阅读进度放在哪里？+

默认从第三方书源 aoya.moe 读取公开作品，实际连接受书源和网络状态影响。阅读进度保存在本机，下次启动会恢复；不需要账号同步。

Ctrl+G 会做什么？+

它将本程序内的阅读界面切换为工作便笺，再按一次恢复阅读。它不会切换到其他办公软件，也不会自动判断你是否需要收起。
